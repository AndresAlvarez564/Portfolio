## Objective
Implement the full projects Lambda (list, create, get by slug, get by ID for admin, update, delete, patch status/featured) and the corresponding public Projects page and admin Projects management pages.

## Proposed Scope
- Backend: all project routes as defined in `backend.md` and `security.md`
- Frontend public: Projects listing page and project detail page
- Frontend admin: Projects list, create form, and edit form
- Observability: CloudWatch alarms and structured logs for the projects Lambda

## Flow

```
Public: GET /projects
↓
Lambda queries GSI-1 gsi1pk=PROJECT gsi1sk begins_with STATUS#published
↓
Returns published projects sorted by createdAt desc

Public: GET /projects/{slug}
↓
Lambda queries GSI-3 gsi3pk=SLUG#<slug> gsi3sk=PROJECT
↓
If not found or not published → 404
↓
Returns project data

Admin: POST /projects
↓
Lambda validates admin group
↓
Validates body, generates UUID projectId and URL-safe slug
↓
Checks slug uniqueness via GSI-3
↓
PutItem pk=PROJECT#<id> sk=METADATA
↓
Returns 201 with created project

Admin: PATCH /projects/{id}
↓
Lambda validates admin group
↓
Updates status or featured field + corresponding GSI key
↓
Returns updated project
```

## Acceptance Criteria
- `GET /projects` returns only published projects
- `GET /projects/{slug}` returns 404 for drafts and non-existent slugs
- `POST /projects` creates a project with a unique slug and returns 201
- `POST /projects` returns 403 without admin group
- `PUT /projects/{id}` updates the project
- `DELETE /projects/{id}` deletes the project and returns 204
- `PATCH /projects/{id}` updates status or featured and updates GSI keys
- Public Projects page renders project cards
- Project detail page renders by slug
- Admin Projects list shows all projects with status and actions
- Admin create/edit form works correctly
- All unit tests pass
- CloudWatch alarms exist for the projects Lambda

## Notes
- GSI key updates on `patch_project` are critical — `gsi1sk` must be updated when `status` changes, `gsi2sk` must be updated when `featured` or `featuredOrder` changes
- `featuredOrder` should be set to the current count of featured projects + 1 when featuring a project
- The public list never returns `draft` projects — this is enforced in the Lambda, not the frontend

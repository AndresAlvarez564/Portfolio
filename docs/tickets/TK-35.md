## Objective
Add screenshot and thumbnail upload capability to the admin project editor. Admins can upload a project thumbnail and multiple screenshots, which are stored in S3 and referenced in the project record.

## Scope
- Backend: project create/update accepts `thumbnailUrl`, `thumbnailS3Key`, `screenshotUrls`, and `screenshotKeys`
- Frontend: `ProjectFormPage` integrates `MediaUpload` for thumbnails and screenshots
- No new Lambda routes - uses existing `PUT /projects/:id` and media routes

## Flow

```text
Admin opens project edit form
Admin uploads thumbnail via MediaUpload (project-thumbnail)
Admin uploads screenshots via MediaUpload (project-screenshot)
Admin saves the project form
PUT /projects/{id} includes thumbnail and screenshot references
Lambda saves those references on the PROJECT record
```

## Objective
Add screenshot and thumbnail upload capability to the admin project editor. Admins can upload a project thumbnail and multiple screenshots, which are stored in S3 and referenced in the project record.

## Proposed Scope
- Backend: update `update_project` to accept `thumbnailUrl`, `thumbnailS3Key`, `screenshotUrls`, `screenshotKeys`
- Frontend: integrate `MediaUpload` component into `ProjectFormPage` for thumbnail and screenshots
- No new Lambda routes — uses existing `PUT /projects/:id` and the media module

## Flow

```
Admin opens project edit form
↓
Admin uploads thumbnail via MediaUpload component (context: project-thumbnail)
↓
MediaUpload calls POST /media/upload → uploads to S3 → POST /media/confirm
↓
Returns cloudfrontUrl and s3Key
↓
Admin uploads screenshots (multiple) via MediaUpload (context: project-screenshot)
↓
Each screenshot goes through the same upload flow
↓
Admin saves the project form
↓
PUT /projects/{id} includes thumbnailUrl, thumbnailS3Key, screenshotUrls, screenshotKeys
↓
Lambda updates project record in DynamoDB
```

## Notes

- The `MediaUpload` component from TK-31 handles the full upload flow — this ticket only integrates it into the project form
- For multiple screenshots, consider a simple list of `MediaUpload` components with an "Add Screenshot" button

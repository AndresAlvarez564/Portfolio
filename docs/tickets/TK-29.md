## Objective
Implement the certifications Lambda routes and the corresponding public Certifications page and admin Certifications management page, including badge image upload via the media module.

## Proposed Scope
- Backend: `GET /certifications` (public), `POST /certifications`, `PUT /certifications/:id`, `DELETE /certifications/:id` (write routes admin only)
- Frontend public: Certifications page with badge images and verification links
- Frontend admin: Certifications management page with CRUD and badge upload
- Observability: CloudWatch alarms and structured logs for the certifications Lambda

## Flow

```
Public: GET /certifications
↓
Lambda queries GSI-1 gsi1pk=CERTIFICATION sort by gsi1sk desc (most recent first)
↓
Returns all certifications

Admin: POST /certifications
↓
Lambda validates admin group
↓
Validates body, generates UUID certificationId
↓
PutItem pk=CERTIFICATION#<id> sk=METADATA
↓
Returns 201

Admin badge upload flow (uses TK-31 media module):
↓
Admin uploads badge image via POST /media/upload → POST /media/confirm
↓
Gets back cloudfrontUrl and s3Key
↓
Admin submits certification form with badgeUrl and badgeS3Key
```

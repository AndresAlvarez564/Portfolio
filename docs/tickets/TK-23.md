## Objective
Deploy the full CDK stack to the dev environment for the first time, create the admin Cognito user, and seed the initial PROFILE_SETTINGS record in DynamoDB so all subsequent feature tickets can be tested end-to-end.

## Proposed Scope
- Run `cdk deploy --all` to deploy AppStack to dev
- Create the admin Cognito user manually and add to the `admin` group
- Seed the PROFILE_SETTINGS singleton record in DynamoDB
- Verify the frontend is accessible via CloudFront
- Verify the API Gateway URL is reachable
- Update `front/.env.local` with real dev outputs

## Flow

```
cdk deploy --all --profile portfolio-dev
↓
Cognito User Pool created → create admin user manually
↓
Add admin user to the admin group
↓
DynamoDB table created → seed PROFILE_SETTINGS record
↓
API Gateway URL available → update front/.env.local
↓
Frontend deployed to S3 → accessible via CloudFront URL
↓
Test login flow end-to-end
```

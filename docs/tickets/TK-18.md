## Objective
Scaffold the React frontend project with Vite, TypeScript, TailwindCSS, and Ant Design.

## Proposed Scope
- Initialize React + Vite + TypeScript project in `front/`
- Install and configure TailwindCSS
- Install and configure Ant Design
- Install React Router
- Install React Hook Form and Yup
- Create folder structure: config, constants, context, hooks, services, components, pages, types
- Create placeholder pages: Home, Projects, Admin Login
- Deploy frontend to S3 and test CloudFront delivery

## Tasks
### Frontend Setup
- [x] Initialize Vite project: `npm create vite@latest front -- --template react-ts`
- [x] Install TailwindCSS: `npm install -D tailwindcss @tailwindcss/vite`
- [x] Configure TailwindCSS via `@tailwindcss/vite` plugin
- [x] Install Ant Design: `npm install antd`
- [x] Install React Router: `npm install react-router-dom`
- [x] Install React Hook Form: `npm install react-hook-form yup @hookform/resolvers`
- [x] Create folder structure in `front/src/`:
  - `config/`
  - `constants/`
  - `context/`
  - `hooks/`
  - `services/`
  - `components/`
  - `pages/`
  - `types/`
- [x] Create placeholder pages based on project requirements
- [x] Configure React Router with routes
- [x] Build frontend: `npm run build`
- [ ] Deploy to S3: `aws s3 sync dist/ s3://<project-name>-dev-frontend-<account-id>`
- [ ] Invalidate CloudFront: `aws cloudfront create-invalidation --distribution-id <id> --paths "/*"`
- [ ] Test CloudFront URL in browser

## Output Files

- `front/src/config/`, `front/src/components/`, `front/src/pages/`, etc.

## Objective
Set up CI/CD pipeline with CodePipeline and CodeBuild for automated deployments.

## Proposed Scope
- Create `PipelineStack` in `infra/lib/pipeline-stack.ts`
- Create CodePipeline with GitHub source
- Create CodeBuild project for build and deploy
- Configure pipeline stages: Source → Build → Deploy

## Tasks
### Infrastructure
- [ ] Create `infra/lib/pipeline-stack.ts`
- [ ] Create CodePipeline: `<project-name>-pipeline`
- [ ] Configure GitHub source connection
- [ ] Create CodeBuild project: `<project-name>-<stage>-build`
- [ ] Configure buildspec.yml for:
  - Install dependencies (infra and frontend)
  - Build frontend: `npm run build`
  - CDK synth: `cdk synth`
  - Deploy AppStage
  - Upload frontend to S3
  - Invalidate CloudFront
- [ ] Configure pipeline stages: Source → Build → Deploy
- [ ] Deploy PipelineStack manually: `cdk deploy PipelineStack --profile <project-name>-dev`

### Build Configuration
- [ ] Create `buildspec.yml` in repository root

## Output Files

- `buildspec.yml`

## Acceptance Criteria
- CodePipeline is created
- Pipeline connects to GitHub repository
- CodeBuild project is configured
- Pipeline can build and deploy the application

## Objective
Implement the public HomePage that serves as the main landing page for visitors. It displays the hero section with profile info, featured projects, and preview sections for experience, skills, and certifications.

## Proposed Scope
- Frontend: complete HomePage with all sections
- Each section fetches its own data independently
- Partial failures are handled gracefully — a failed section shows a fallback, not a full-page error

## Flow

```
Visitor navigates to /
↓
HomePage mounts and fires parallel API calls:
  - GET /profile → hero section
  - GET /projects?featured=true → featured projects section
  - GET /experience → experience preview (first 2-3 entries)
  - GET /skills → skills preview (visible only)
  - GET /certifications → certifications preview (first 3)
↓
Each section renders independently as data arrives
↓
Failed sections show empty state or fallback message
```

## Notes
- Use `Promise.allSettled` (not `Promise.all`) so a single failed API call does not block the entire page
- The hero image (`front/src/assets/hero.png`) can be used as a placeholder until a real photo is uploaded
- Featured projects are ordered by `featuredOrder` — the backend returns them in the correct order
- Keep the homepage fast: all API calls are parallel, no sequential dependencies

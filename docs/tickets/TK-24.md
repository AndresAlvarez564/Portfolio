## Objective
Implement the profile Lambda routes and the frontend About page so visitors can view Andres's profile and the admin can update it from the admin panel.

## Proposed Scope
- Backend: implement `GET /profile` (public, sanitized) and `PUT /profile` (admin only)
- Frontend public: About page displaying name, title, summary, location, social links, and CV download
- Frontend admin: Profile Settings page with edit form
- Observability: CloudWatch alarms and structured logs for the profile Lambda

## Flow

```
Public visitor navigates to /about
↓
Frontend calls GET /profile
↓
Lambda reads PROFILE_SETTINGS from DynamoDB (pk=PROFILE sk=SETTINGS)
↓
Lambda returns sanitized fields (excludes email and internal fields)
↓
About page renders profile info

Admin navigates to /admin/settings
↓
Frontend calls GET /profile (full response for admin)
↓
Admin edits fields and submits
↓
Frontend calls PUT /profile with JWT
↓
API Gateway validates JWT → Lambda checks admin group
↓
Lambda validates body and updates DynamoDB
↓
Frontend shows success message
```

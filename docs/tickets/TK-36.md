## Objective
Implement a complete, editable About Me experience. Andres must be able to edit About Me content from the admin panel, the public `/about` page must render that content, and the Home page must show a short About preview that links to the full page.

## Proposed Scope
- Frontend: replace the placeholder `/about` page with a full responsive page.
- Admin: extend Profile Settings so About Me content can be edited without code changes.
- Backend: persist About Me fields through the existing profile settings record.
- Home: add an About preview section using the same editable content.
- Data: use profile data from `GET /profile`.

## Page Sections
- Hero intro: name, title, location, short positioning statement.
- Professional story: concise background and why Solutions Architecture.
- Cloud focus: AWS, serverless, security, infrastructure, and backend systems.
- What I build: portfolio CRM, APIs, admin tools, event-driven flows, media workflows.
- Learning path: certifications and current AWS study direction.
- Work values: clarity, reliability, documentation, and practical delivery.
- CTA: links to Projects, Certifications, Contact, and CV when available.

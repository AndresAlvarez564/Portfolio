## Objective
Configure CodeDeploy for Lambda with aliases and CloudWatch alarms for safe deployments with automatic rollback.

## Proposed Scope
- Update `LambdasConstruct` to use Lambda versions and aliases
- Create CodeDeploy deployment groups for each Lambda
- Attach CloudWatch alarms for automatic rollback
- Configure deployment strategy: All-at-once for dev, Canary for prod

## Tasks
### Infrastructure
- [ ] Update `infra/lib/constructs/lambdas.ts`
- [ ] Create Lambda versions for each function
- [ ] Create Lambda alias: `live` for each function
- [ ] Create CodeDeploy deployment group for each Lambda
- [ ] Configure deployment strategy:
  - Dev: All-at-once
  - Staging: Linear10PercentEvery1Minute
  - Prod: Canary10Percent5Minutes
- [ ] Attach CloudWatch error alarms to deployment groups
- [ ] Update API Gateway to use `live` alias instead of `$LATEST`
- [ ] Deploy to dev: `cdk deploy --profile portfolio-dev`

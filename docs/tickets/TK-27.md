## Objective
Implement the experience Lambda routes and the corresponding public Experience page and admin Experience management page, including drag-to-reorder functionality.

## Proposed Scope
- Backend: `GET /experience` (public), `POST /experience`, `PUT /experience/:id`, `DELETE /experience/:id`, `PATCH /experience/reorder` (all write routes admin only)
- Frontend public: Experience page listing all entries ordered by `order` field
- Frontend admin: Experience management page with CRUD and drag-to-reorder
- Observability: CloudWatch alarms and structured logs for the experience Lambda

## Flow

```
Public: GET /experience
↓
Lambda queries GSI-1 gsi1pk=EXPERIENCE, sort by gsi1sk (ORDER#<padded>)
↓
Returns all experience entries sorted by order field

Admin: POST /experience
↓
Lambda validates admin group
↓
Validates body, generates UUID experienceId
↓
Sets order = current count + 1
↓
PutItem pk=EXPERIENCE#<id> sk=METADATA
↓
Returns 201

Admin: PATCH /experience/reorder
↓
Lambda validates admin group
↓
Receives orderedIds: [id1, id2, id3, ...]
↓
For each id, UpdateItem: order = index + 1, gsi1sk = ORDER#<padded>
↓
Returns updated list
```

- `DELETE /experience/{id}` deletes the entry and returns 204

## Notes
- `order` values are 1-based integers; `gsi1sk` stores them zero-padded to 3 digits: `ORDER#001`
- Reorder receives the full ordered list of IDs — Lambda updates all of them
- `current=true` means the person is still in this role; `endDate` should be null in this case
- Install `@dnd-kit/core` and `@dnd-kit/sortable` for drag-and-drop if not already in `package.json`

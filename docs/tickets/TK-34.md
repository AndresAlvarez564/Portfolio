## Objective
Implement the admin Dashboard page that gives Andres a quick overview of the portfolio content status: project counts, unread messages, and quick navigation links to each admin section.

## Proposed Scope
- Frontend: Dashboard page with stat cards and quick links
- No new backend routes needed — uses existing admin endpoints

## Flow

```
Admin navigates to /admin/dashboard
↓
Dashboard fires parallel API calls:
  - GET /projects/admin → project stats (total, published, draft, featured)
  - GET /contact?status=unread → unread message count
↓
Renders stat cards and quick navigation links
```

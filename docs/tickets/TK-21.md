## Objective
Implement route protection to ensure only authenticated users with appropriate permissions can access protected routes.

## Proposed Scope
- Create ProtectedRoute component
- Check authentication status before rendering protected routes
- Check Cognito group membership based on route requirements
- Redirect unauthenticated users to login
- Show "Access Denied" for authenticated users without required permissions

## Flow

```
User navigates to protected route
↓
ProtectedRoute checks authentication
↓
If not authenticated → redirect to login
If authenticated but missing required group → show "Access Denied"
If authenticated with required group → render route
```

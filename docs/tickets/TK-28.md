## Objective
Implement the skills Lambda routes and the corresponding public Skills page and admin Skills management page.

## Proposed Scope
- Backend: `GET /skills` (public, visible only), `POST /skills`, `PUT /skills/:id`, `DELETE /skills/:id` (write routes admin only)
- Frontend public: Skills page grouped by category
- Frontend admin: Skills management page with CRUD
- Observability: CloudWatch alarms and structured logs for the skills Lambda

## Flow

```
Public: GET /skills
↓
Lambda queries GSI-1 gsi1pk=SKILL gsi1sk begins_with VISIBILITY#visible
↓
Returns visible skills grouped by category

Admin: POST /skills
↓
Lambda validates admin group
↓
Validates body, generates UUID skillId
↓
PutItem pk=SKILL#<id> sk=METADATA
↓
Returns 201

Admin: PUT /skills/{id}
↓
Lambda validates admin group
↓
Validates body, UpdateItem
↓
If visibility or category changed → update gsi1sk accordingly
↓
Returns updated skill
```

## Notes
- `gsi1sk` pattern: `VISIBILITY#<visibility>#<category>` — must be updated on every PUT if visibility or category changes
- The public page only shows `visibility=visible` skills — this is enforced in the Lambda
- Allowed categories are fixed: `cloud`, `backend`, `frontend`, `devops`, `databases` — validate in Lambda

## Objective
Implement the skills Lambda routes and the corresponding public Skills page and admin Skills management page.

## Proposed Scope
- Backend: `GET /skills` (public, visible only), `GET /skills/admin`, `POST /skills`, `PUT /skills/:id`, `DELETE /skills/:id` (admin write routes)
- Frontend public: Skills page grouped by category
- Frontend admin: Skills management page with CRUD
- Observability: CloudWatch alarms and structured logs for the skills Lambda

## Flow

```text
Public: GET /skills
- Lambda queries GSI-1 gsi1pk=SKILL and gsi1sk begins_with VISIBILITY#visible
- Returns visible skills grouped by category on the frontend

Admin: POST /skills
- Lambda validates admin group
- Validates body, generates UUID skillId
- PutItem pk=SKILL#<id> sk=METADATA
- Returns 201

Admin: PUT /skills/{id}
- Lambda validates admin group
- Validates body and existing item
- Updates gsi1sk when visibility or category changes
- Returns updated skill
```

## Objective
Implement login page, logout functionality, and session handling for the admin panel.

## Proposed Scope
- Create login page with email and password fields
- Implement sign-in logic using Amplify
- Implement sign-out logic
- Create AuthContext to manage authentication state
- Store user session and check authentication status
- Redirect to appropriate dashboard after successful login

## Flow

```
User navigates to protected route
↓
If not authenticated → redirect to login page
↓
User enters email and password
↓
Frontend calls Amplify signIn
↓
Cognito validates credentials
↓
On success → store session and redirect to dashboard
On error → show error message
```

- Store minimal user info in AuthContext (email, groups)
- Do not store sensitive tokens in localStorage — let Amplify handle it
